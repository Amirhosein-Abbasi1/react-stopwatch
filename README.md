# ⏱️ React Stopwatch

A modern and responsive stopwatch application built with React, showcasing React Hooks, state management, and clean component architecture.

## ✨ Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the timer
- 🏁 Record lap times
- 🌙 Light / Dark mode
- 📱 Responsive design
- ⚡ Smooth user experience

## 🛠️ Built With

- React
- JavaScript (ES6+)
- CSS3
- React Hooks

## 🚀 Getting Started

```bash
git clone https://github.com/Amirhosein-Abbasi1/react-stopwatch

cd react-stopwatch
npm install
npm run dev
```
